찾고, 이해하고, 고치세요.

외부 Pull Request를 처리하는 워크플로에서 토큰 권한이 과도하게 부여되거나, 검토하지 않은 외부 Action이 실행되는 위험을 줄이세요. Workflow Risk Check는 무료 정적 검사 도구와, 필요한 경우 별도 협의를 통해 진행하는 GitHub Actions YAML 수정 서비스를 제공합니다.

워크플로 YAML 한 개부터 점검

어떤 설정을 살펴보나요?

GITHUB_TOKEN 최소 권한

permissions: write-all과 외부 이벤트의 쓰기 권한처럼 추가 검토가 필요한 설정을 찾습니다. 실제 허용 범위는 저장소·조직 정책에 따라 달라집니다.

외부 Action 고정

actions/checkout@v4 등 변경 가능한 태그 참조를 찾아, 감사한 전체 커밋 SHA로 고정해야 할 위치를 안내합니다.

PR의 신뢰 경계

pull_request_target에서 외부 포크 코드가 실행될 수 있는 일부 위험 조합과 이벤트 데이터를 셸 코드로 직접 사용하는 패턴을 점검합니다.

러너 및 재사용 워크플로

자체 호스팅 러너, secrets: inherit, workflow_run 산출물처럼 상황에 따라 추가 분리가 필요한 항목을 표시합니다.

수정 작업을 의뢰한다면

소규모 저장소를 위한 서비스 안내가는 미화 149달러부터입니다. 구체적인 작업 내용, 접근 방법, 일정과 비용은 상담을 통해 먼저 정합니다. 현재 사이트에서는 결제나 자동 계약이 이루어지지 않습니다.

기본 범위의 예: GitHub Actions YAML 최대 5개 검토, 중요한 설정 문제의 우선순위화, 합의된 내용에 대한 수정 Pull Request 1건, 후속 검토 1회. 대규모 리포지토리, 자체 호스팅 인프라, 배포 키·시크릿 변경, 모의 침투 테스트는 기본 범위에 포함되지 않습니다.

진행 절차

  1. 무료 점검: 브라우저에서 YAML을 검사하고 발견 항목을 확인합니다.
  2. 비민감 정보로 상담: 공개 저장소 링크 또는 비밀정보 없는 작업 범위를 GitHub 이슈로 보내주세요.
  3. 작업 조건 합의: 접근 권한, 납기, 비용, 결과물을 합의하기 전에는 유료 작업을 시작하지 않습니다.
  4. 수정 및 재확인: 합의된 PR 변경과 실행 가능한 검증 결과를 전달합니다.

공개 YAML 1개 4 USDC 소액 점검: Clawlancer에서 실제 등록된 4 USDC 고정가격 상품 주문 ↗. GitHub Actions YAML 최대 300줄을 분석하고 원본 줄 번호가 있는 근거 보고서(또는 확인된 문제 없음)와 작은 수정 제안 최대 2개를 제공합니다. AI 지원 정적 분석이며, 고객의 결제·작업 범위 합의 후 24시간을 목표로 합니다. 침투 테스트·수정 PR·보안 보증이 아닙니다. 이 가격은 판매 제안일 뿐 실제 고객 구매나 지급은 아직 0건입니다.

공개 저장소의 GitHub Actions YAML 파일 최대 3개에 대한 간단한 서면 검토만 필요하다면 Clawlancer의 25 USDC 소규모 검토 상품을 이용할 수 있습니다. Base 네트워크의 USDC와 거래 가스비가 구매자에게 필요합니다. 확인된 에스크로와 정확한 범위 합의 후 진행하며, 별도 수정 PR이나 포괄적 보안 인증은 포함되지 않습니다. 가상 YAML을 이용한 보고서 예시를 참고하세요. 아직 실제 구매 및 지급은 확인되지 않았습니다.

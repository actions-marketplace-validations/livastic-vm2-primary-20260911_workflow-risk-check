DETAILS

Read before you rely on it.

Is this a complete security audit?

No. It checks selected, high-signal patterns in a single workflow file. It cannot inspect runtime behavior, repository settings, external actions, or other workflows.

Does the checker transmit my YAML?

No. The parser and analyzer run in your browser and the interface has no document-upload or analytics endpoint. Source links only open if you click them.

Are unpinned tags always vulnerable?

No. Mutable refs are a supply-chain exposure, not proof of an active compromise. Findings are prompts for review and control improvements.

How do I request paid help?

Submit the short Google Forms scope inquiry with a reply email and non-sensitive project summary (no GitHub sign-in required), or use the public GitHub issue alternative. We'll confirm access method, exact deliverables, timeline and a fixed quote before any paid work starts.

How can I clarify the scope before requesting a quote?

Consider ScopeLens, a separate free, local-first brief checklist. It can help structure deliverables, acceptance criteria and payment terms; it is not a security audit or paid partnership.
